# Community server

## Getting help here
Use /support with your question. The bot answers from these help docs in a thread of its own and lists the sources it used. If the docs don't cover it, or you'd rather talk to a person, press Talk to a human and a moderator joins the thread.

## Server rules
Be kind. No spam, no advertising, no invite links to other servers, and no sharing other people's personal details. Never post your password, backup codes or payment details here: staff will never ask for them in Discord.

## Reporting a message
Right-click a message (or long-press on mobile), choose Apps > Report to moderators. Only moderators see the report. The bot never removes anything on its own; a moderator decides.

## Feature requests
Post ideas in the #ideas channel. The team reads them every week and marks the ones that are planned.
